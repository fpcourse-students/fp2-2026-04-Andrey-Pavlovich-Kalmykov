# Общая инфраструктура домашних заданий

Инфраструктуру, полезную нескольким домашкам, развиваем в `fp2026/haskell-homework-template`: общие команды Makefile, workflow, библиотеки и проверялки добавляются туда сразу. Новые домашки наследуют эти возможности из шаблона. Состав файлов и особенности конкретной домашки определяются её заданиями; совпадение с шаблоном не требуется.

В `fp2026/hws` команда `make new HW=NN` создаёт домашку из общего шаблона. Обновления существующих репозиториев переносятся обычным Git: `make release` выполняет `git pull template main`, сохраняя историю и позволяя разрешить конфликты с особенностями домашки.

Преподавательские цели и их описания находятся внизу Makefile. Обычный `make` показывает только студенческие команды. Общие Python-инструменты находятся в `meta-utils/` и вызываются через Makefile. `make check-report` проверяет отчёт заготовки по TASKS, а `make tools-test` проверяет этот инструмент и обновление ветки эталона. `make checker-check` проверяет λ-проверялку.

Содержательные примеры приложений в `app/Main.hs` сохраняются при переносе домашок. Общий шаблон содержит необязательный компонент `homework-exe` и команду `make run ARGS="…"`. В домашках с приложением компонент включается флагом `+app` в `variant.project`.

`make publish-template MSG="Описание изменений"` проверяет инструменты и строгую сборку, коммитит изменения общего шаблона и отправляет main в `fpcourse-materials/haskell-homework-template`. Общий шаблон публичный и содержит только обвязку; репозитории домашних заданий с эталонами остаются приватными.

Для публикации домашки служит `make release PUBLIC_REPO=организация/имя`: условия остаются в main, эталон — в solutions приватного origin, публичный студенческий шаблон получает только main. Общие файлы, тесты и конфигурация ветки solutions обновляются из main через `make solutions-sync`; эта цель сохраняет файлы решений `src/Level1.hs`, `src/Level2.hs`, `src/Level3.hs` и `src/hw.lam`. Дедлайн для этой процедуры не требуется.

Публичный шаблон получает снимок дерева main с отдельной историей: первый снимок не имеет родителей, следующие продолжают только публичную ветку. Приватные коммиты и старые слияния с эталонами не переносятся. `meta-utils/publish_public.py` выполняет обычный push без принудительной перезаписи; тесты публикации входят в `make tools-test`.
